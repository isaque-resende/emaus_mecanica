# E0 · Mecânica (rascunho)

Visualização bem simples da mecânica do E0 ("A palavra que define o bom", Gn 1-2) do jogo *No caminho de Emaús*.
Não é protótipo: serve só para perceber o fluxo das etapas, cartas e peças.
